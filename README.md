# 還付金試算ツール

給与明細から、年末調整の過不足・確定申告での還付・ふるさと納税の上限を年の途中から見通す個人用ツール。仕様は [docs/requirements.md](docs/requirements.md)。

- データはブラウザの IndexedDB にだけ保存し、外部に送信しない（本番ビルドは CSP で外部接続を禁止）
- PDF はブラウザ内の pdf.js で読む。API キー不要
- 税制の値は [params/](params/) の年分別 JSON に置き、各値に一次資料の URL と確認状態を持たせる

## 使い方

1. 給与明細画面で、給与・賞与明細と源泉徴収票の PDF をまとめて選んで取り込む（検算5本と累計照合を通らない明細は登録しない）
2. 控除画面で家族・保険契約を登録する
3. ダッシュボードで年調過不足・還付見込み・ふるさと残枠を確認する
4. 医療費・ふるさと納税を随時登録する。試算結果画面で計算過程と根拠を確認する

育児休業などで給与が出ない月は、給与明細画面の「休業（無給）の月」で指定する（予測の給与・賞与・社会保険料・源泉税が0になり、年税額とふるさと上限に反映）。賞与など個別の金額はグリッドのセルから手入力できる。ふるさと納税画面の「仮置きで試す」は保存されない試算用。

社会保険料は、4〜6月の報酬平均による定時決定と、固定的賃金の変動による随時改定（2等級以上）から、10月支給分などの改定後の保険料を予測する。健康保険の料率は明細の保険料から推定し、設定画面で手入力もできる。

PC と iPhone の間は、設定画面のバックアップ（任意で AES-GCM 暗号化）で移す。

## 開発

```powershell
npm install
npm run dev           # http://localhost:5173
npm run test          # 合成データのみ
npm run typecheck
npm run lint
npm run build
npm run verify:local  # private/ の実物PDFで源泉徴収票と突合（ローカル専用・CIでは実行しない）
```

`private/` 配下（PDF・取込結果・エクスポート）は `.gitignore` 済み。`npm run check:private` が CI で個人データの混入を検査する。

## 構成

| パス               | 内容                                                           |
| ------------------ | -------------------------------------------------------------- |
| `src/engine/`      | 税計算エンジン（純粋関数、計算過程トレース付き）               |
| `src/import/`      | PDF 読取（明細の格子ルール、源泉徴収票のラベル基準読取、検算） |
| `src/domain/`      | 予測・比較・年間集計・取込計画・DB・バックアップ               |
| `src/app/`         | 画面（React）                                                  |
| `params/<年>.json` | 税制パラメータ（2024〜2026年分）                               |

## 対応範囲の制限

- 障害者控除・寡婦／ひとり親控除・配偶者控除・特定親族特別控除は未対応（現在の家族構成では不要）
- 令和9年分以降は `params/2027.json` の追加が必要（復興特別所得税が防衛特別所得税と組み替えになる）
