# ふるさと納税上限の検算（ポータルサイトのシミュレーター）

実施日：2026-10-15。対象：2026年分（令和8年分）の税制。

外部サイトには実際の給与額ではなく **合成のテストケース** を入力した（本ツールは個人データを端末外に送らない方針のため）。
独身・扶養なし・住宅ローン控除なし・医療費控除なし。同じケースを `src/engine/engine.test.ts` の回帰テストに固定している。

## 差の説明

- **ふるさとチョイス**：生命保険のない4ケースは円単位で一致。B の差（−316円）は、チョイスが入力欄「生命保険料の控除額（所得税ベース）」の4万円を住民税にもそのまま使うため。住民税の法定額は2.8万円（新契約・支払10万円）で、本ツールはこちらを使う。所得割はチョイス 525,500円・本ツール 526,600円。
- **ふるなび**：千円未満を切り捨てて表示する。本ツールの値を千円単位に切り捨てると5ケースとも一致（保険料の支払額を入力する方式のため、B の住民税の生命保険料控除も一致）。
- **さとふる**：課税所得（所得税）は5ケースとも一致。住民税所得割が常に2,500円高いのは、調整控除を計算に入れていないため。そのため C だけ千円単位で1,000円高くなる。なお詳細版は「源泉徴収票の所得控除合計は前年（2025年）の基礎控除で計算されている」とみなし、2026年の引上げ分を自動で加算する。このため入力には2025年基準の所得控除合計を使った。
- **楽天ふるさと納税**：詳細版（2026年分）は、同じ入力でも質問への答え方によって結果が大きく変わり（A で 52,179〜71,933円）、計算の前提を外部から特定できなかったため対象外とした。早見表（年収600万円・独身で79,000円、900万円で155,000円）は、チョイスとふるなびの早見表（77,000円、152,000円）より2〜3%高く、社会保険料の想定が異なるとみられる。

## 早見表（社会保険料＝給与収入の15%）との照合

ふるさとチョイスとふるなびの早見表で、独身・年収600万円は77,000円、400万円は42,000円。本ツールの A（77,322円）、D（42,167円）と千円単位で一致する。

## 参考：今後の制度改正

ふるさとチョイスに「2027年1月 ふるさと納税制度改正（住民税特例控除上限設定）」のお知らせがある。2027年以降の寄付は特例控除額に上限が設けられる見込みのため、`params/2027.json` を追加する際に一次資料で確認すること。
